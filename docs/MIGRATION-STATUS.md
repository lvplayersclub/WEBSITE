# Pārnešanas statuss

Kods, palaišanas konfigurācija un publicētā satura kopija ir sagatavota. Publiskajām lapām nav paroles; administratora piekļuve ir aizsargāta.

No 44 augšupielādētiem failiem pakotnē pašlaik ir 22. Vēl jāiegūst 22 faili. Lejupielādi no jaunās Sites adreses apturēja automatizētā drošības pārbaude. Faili nav aizstāti ar citām bildēm.

Pirms patstāvīgās vietnes publicēšanas pabeidz attēlu pārnešanu un palaid `pnpm check:assets`. Palīgkomanda `pnpm media:fetch` veic tikai publiskus HTTP pieprasījumus (bez parolēm vai piekļuves tokeniem). Ja tavā datorā avota vietne šos pieprasījumus neatļauj, vajadzīga autorizēta failu pārnešana no vietnes īpašnieka sesijas vai failu pievienošana ar roku.
