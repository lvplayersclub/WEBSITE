# Pārnešanas statuss

Attēlu un video pārnešana pabeigta 2026-11-07. Visi 44 mediju sarakstā norādītie augšupielādētie faili ir pieejami `public/assets/imported/`, tostarp iepriekš trūkstošais 21 attēls un 1 video. Faili lejupielādēti pilnā apjomā no sākotnējās vietnes; oriģināli nav aizstāti.

Kods, palaišanas konfigurācija un publicētā satura kopija ir sagatavota. Publiskajām lapām nav paroles; administratora piekļuve ir aizsargāta.

`pnpm check:assets` pārbauda publicētā satura failu esamību. GitHub pārbaude izpilda arī koda pārbaudi, testus un būvēšanu.

Pirms patstāvīgas publicēšanas vēl jāizveido sava Cloudflare D1 datubāze un R2 glabātava, jānorāda datubāzes ID un droši jāiestata administratora piekļuve un publicēšanas noslēpumi, kā aprakstīts README. Šie konta iestatījumi netiek pievienoti publiskajam kodam.
